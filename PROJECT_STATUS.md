# Kerfuffle — статус проекта

Последнее обновление: 12 ноября 2026 г.

## Что сделано

- Backend на FastAPI, SQLAlchemy и PostgreSQL; одиннадцать ORM-моделей, миграции
  Alembic с ограничениями целостности и триггерами.
- OIDC-проверка токенов по JWKS, `issuer`, `audience`, сроку действия и `sub`.
  Первый системный администратор создаётся только по явно настроенному
  `OIDC_BOOTSTRAP_ADMIN_SUBJECT`; другие пользователи автоматически не
  добавляются.
- Просмотр аккаунта и доступов (`GET /api/v1/me`), список мероприятий,
  создание мероприятия системным администратором или выданным им организатором
  с автоматическим назначением создателю роли организатора.
- Создание, просмотр и изменение площадок; проверка шкалы и запрет менять её
  после первой оценки. Ведущий видит только назначенные площадки.
- Поиск карточек людей, регистрация существующего или нового человека и
  список регистраций. Номер последовательно назначается в мероприятии, QR —
  случайный UUID. Контактные и необязательные персональные данные не выдаются
  в поиске и списке участников.
- Поиск участника на площадке по QR или номеру; выставление одной допустимой
  оценки и исправление оценки организатором.
- Публичный рейтинг: сумма, место с равенством при одинаковых суммах,
  имя, номер и баллы по каждой площадке; видны в том числе участники с нулём
  баллов. Контактные и необязательные персональные данные публично не выдаются.
- Номера участников теперь шестизначные. Миграция `0002` дополняет ведущими
  нулями существующие цифровые номера и останавливается на некорректных либо
  конфликтующих значениях.
- Frontend React + Vite + TypeScript: адаптивная главная, публичный рейтинг с
  поиском, именами и прогрессом по каждой площадке, обновлением каждые пять
  секунд. Подключены Authorization Code + PKCE через `oidc-client-ts`,
  кабинет с существующими API событий/площадок/регистраций и рабочий экран
  начисления с серверной проверкой площадки, Stepper и защитой от повторов.
- Добавлены dev-конфигурация Keycloak, импорт realm с публичным клиентом и
  PKCE S256. Для этой Windows-среды скачаны официальные Keycloak 26.3.3 и
  Temurin Java 21 с проверкой SHA; Keycloak запущен без Docker. Создан
  локальный пользователь организатора, конфигурация OIDC backend/frontend
  подготовлена. Пользователь сопоставлен с уже созданным системным
  администратором в PostgreSQL, одноразовая bootstrap-настройка удалена из
  локального `backend/.env`; остаётся отдельно проверить интерактивный вход
  в браузере.
- Добавлены организаторский журнал начислений, исправление и аннулирование
  оценок с обязательной причиной; каждое изменение атомарно записывается в
  новую append-only таблицу `score_audit`; триггер БД запрещает изменение и
  удаление записей аудита. Аннулированная оценка остаётся зарезервированной
  для пары участник/площадка и не учитывается в рейтинге.
- Системный администратор создаёт учетные записи организаторов через отдельный
  Keycloak service account с `manage-users`. Генерируемый пароль временный,
  показывается только в ответе создания, а аккаунт требует смены пароля при
  первом входе.
- Организатор может создавать и отключать неограниченные по сроку и числу
  использований коды регистратора и коды с заранее закреплённой площадкой.
  Backend хранит только HMAC-хеши; отключение кода отзывает и активные
  сессии, которые истекают через 12 часов.
- Публичные экраны регистрации и начисления подключены к кодовым сессиям:
  мероприятие/площадка выбираются кодом на сервере, регистрация получает
  шестизначный номер, а поиск/начисление используют существующие серверные
  проверки шкалы и уникальности.
- Ограниченная роль PostgreSQL `kerfuffle_app`: SELECT/INSERT/UPDATE/DELETE и
  доступ к identity sequences, без права создавать объекты в схеме. Её пароль
  сохранён только в игнорируемом `backend/.env`, не в репозитории.

## Состояние локального окружения

- PostgreSQL на `127.0.0.1:5432`, база `kerfuffle` доступны.
- Существующая схема проверена сравнением с ORM без расхождений и помечена
  Alembic-ревизией `0001_initial`; миграция `0002_six_digit_ids` успешно
  применена владельцем схемы. На момент миграции регистраций не было.
- Миграции `0003_score_audit`, `0004_immutable_score_audit` и
  `0005_scoped_access_codes` применены к PostgreSQL от имени владельца схемы;
  текущая ревизия — `0005`.
- Runtime-роль имеет необходимые права на журнал аудита и таблицы кодов; она
  не может создавать объекты в схеме. PostgreSQL-триггер неизменяемости
  установлен.
- API успешно подключается к базе под ограниченной ролью; тестовая вставка
  для проверки прав была отменена транзакцией.
- Node.js LTS и npm установлены для создания frontend-приложения.
- Backend-тесты включают SQLite; отдельно проверены генерация SQL миграции и
  чтение состояния PostgreSQL.
- Node.js доступен по `C:\Program Files\nodejs`; PowerShell-сеансу может
  потребоваться добавить этот каталог в `PATH` перед вызовом npm.
- Для этой разработки новый backend запущен на `127.0.0.1:8001`: порт 8000
  занят старым процессом Kerfuffle, который не принадлежит доступному shell
  и продолжает отдавать прежний OpenAPI. Vite proxy и frontend-инструкция
  настроены на 8001.
- Секреты хеширования кодов и Keycloak service account настроены только в
  игнорируемом `backend/.env`. Service account выдаёт client-credentials
  токен и проходит проверку минимального доступа к Keycloak Users API.
- Привязка OIDC-учётной записи и роль системного администратора в PostgreSQL
  проверены. Локальная учётная запись включена, обязательная смена пароля в
  Keycloak не ожидается; успешный вход из текущей браузерной вкладки ещё не
  подтверждён. Не отправляйте локальные пароли в чат.

## Проверки

- Backend: из `backend` выполнить `python -m pytest`.
- Frontend: из `frontend` выполнить `npm run build` и `npm run lint`.
- Текущая проверка: Backend — 45 тестов прошли; Frontend build и lint прошли;
  PostgreSQL health и кодовые routes проверены на новом backend. Сквозное
  создание аккаунта через UI и реальную регистрацию/оценку ещё нужно проверить.
- Миграции выполняются ролью-владельцем БД; `kerfuffle_app` предназначена
  только для работы приложения.
